# ITS3ABDO Portfolio

Responsive personal portfolio built with HTML, CSS and JavaScript.

Open `index.html` in a modern browser or host this folder as a static website.

## Included media
- `media/music.mp3` — plays after the visitor presses ENJOY.
- `media/backgrounds/desktop-bg.webp` and `mobile-bg.webp` — responsive backgrounds.
- `media/featured/work-1.jpg` through `work-5.jpg` — featured gallery.
- `media/edits/edit-1.mp4` through `edit-5.mp4` — video edits.

Social links, website links and contact details are edited in `index.html`. No admin panel or database is used.
